# BioInspire-Triplets Experiment Repository

This repository contains the code used for model fine-tuning, inference, and, evaluation for the **BioInspire-Triplets** dataset.

BioInspire-Triplets is designed for extracting structured **Source–Prototype–Application (SPA)** relations from scientific literature. The experiments in this repository evaluate the performance of `meta-llama/Llama-3.1-8B-Instruct` and `Qwen/Qwen3-8B` before and after LoRA-based supervised fine-tuning.

The dataset itself is distributed separately through the dataset repository. To reproduce the experiments, download the dataset and place the required files in the corresponding directories described below.

## Directory Description

### `data/`

Contains the dataset partitions used for supervised fine-tuning and evaluation.

```text
data/
├── train.json
├── validation.json
└── test.json
```

The dataset files should be downloaded separately from the BioInspire-Triplets dataset repository and placed in this directory before running the experiments.

### `logs/`

Stores logs generated during model training, inference, and related experiments.

### `model/`

Stores the downloaded base model files.

```text
model/
├── llama/
└── qwen/
```

* `model/llama/`: stores `meta-llama/Llama-3.1-8B-Instruct`.
* `model/qwen/`: stores `Qwen/Qwen3-8B`.

The models can be downloaded using `scripts/model_download.py`.

### `outputs/`

Stores model checkpoints and inference outputs.

```text
outputs/
├── llama/
│   ├── base_infer/
│   ├── lora/
│   └── lora_infer/
│
└── qwen/
    ├── base_infer/
    ├── lora/
    └── lora_infer/
```

For Llama:

* `outputs/llama/base_infer/`: inference results generated by the base Llama model.
* `outputs/llama/lora/`: LoRA fine-tuning outputs and checkpoints.
* `outputs/llama/lora_infer/`: inference results generated by the fine-tuned Llama model.

For Qwen:

* `outputs/qwen/base_infer/`: inference results generated by the base Qwen model.
* `outputs/qwen/lora/`: LoRA fine-tuning outputs and checkpoints.
* `outputs/qwen/lora_infer/`: inference results generated by the fine-tuned Qwen model.

### `scripts/`

Contains the main scripts required to reproduce the model experiments.

* `calculate_llama.py`: calculates evaluation metrics for Llama predictions.
* `calculate_qwen.py`: calculates evaluation metrics for Qwen predictions.
* `evaluate_llama.py`: runs inference using the Llama base or fine-tuned model.
* `evaluate_qwen.py`: runs inference using the Qwen base or fine-tuned model.
* `model_download.py`: downloads the required base models.
* `train_llama.py`: performs LoRA fine-tuning for Llama.
* `train_qwen.py`: performs LoRA fine-tuning for Qwen.

### `requirements.txt`

Contains the Python dependencies required for running the experiments.

# Evaluation

The evaluation scripts calculate strict-match performance for the three SPA components:

* Source
* Prototype
* Application

as well as the complete:

* Source–Prototype–Application triplet

The reported metrics include:

* Precision
* Recall
* F1-score

## Evaluate Llama predictions

Run:

```bash
python scripts/calculate_llama.py
```

## Evaluate Qwen predictions

Run:

```bash
python scripts/calculate_qwen.py
```

The evaluation uses normalized exact matching between predicted and gold-standard textual values.

A complete SPA triplet is considered correct only when the predicted Source, Prototype, and Application jointly match the corresponding gold-standard relation.

# Reproducing the Experiments

The complete experimental workflow is summarized below.

### Step 1. Install dependencies

```bash
pip install -r requirements.txt
```

### Step 2. Download the base models

```bash
python scripts/model_download.py
```

Ensure that the models are available under:

```text
model/
├── llama/
└── qwen/
```

### Step 3. Download the dataset

Download the BioInspire-Triplets dataset from the dataset repository and place:

```text
train.json
validation.json
test.json
```

under:

```text
data/https://doi.org/10.5281/zenodo.22263012
```

### Step 4. Fine-tune the models

For Llama:

```bash
python scripts/train_llama.py
```

For Qwen:

```bash
python scripts/train_qwen.py
```

### Step 5. Run base-model inference

Configure the corresponding evaluation script to use the base model and run:

```bash
python scripts/evaluate_llama.py
```

or:

```bash
python scripts/evaluate_qwen.py
```

The outputs are stored under:

```text
outputs/llama/base_infer/
outputs/qwen/base_infer/
```

### Step 6. Run fine-tuned-model inference

Configure the corresponding evaluation script to load the LoRA-fine-tuned model and run:

```bash
python scripts/evaluate_llama.py
```

or:

```bash
python scripts/evaluate_qwen.py
```

The outputs are stored under:

```text
outputs/llama/lora_infer/
outputs/qwen/lora_infer/
```

### Step 7. Calculate evaluation metrics

For Llama:

```bash
python scripts/calculate_llama.py
```

For Qwen:

```bash
python scripts/calculate_qwen.py
```

The scripts report strict-match Precision, Recall, and F1-score for Source, Prototype, Application, and complete SPA triples.

# Notes

The dataset and the experimental code are distributed separately.

This repository primarily contains:

* model downloading scripts;
* LoRA fine-tuning scripts;
* model inference scripts;
* strict-match evaluation scripts.

The dataset repository contains the data required to reproduce the experiments. Users should download the dataset separately and place the corresponding files under `data/` before running the training or evaluation scripts.

Model files are not included directly in this repository and should be downloaded using the provided model download script.

Large model checkpoints and experimental outputs may also be excluded from the GitHub repository because of their file size.
